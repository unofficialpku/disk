# PKUDisk v0.3.8

Capacity and file sizes now use readable IEC units by default. `-b/--bytes`
selects exact byte counts for `ls`, `util quota`, `util search`, `recover`,
upload/download output and progress, mount diagnostics, and TUI remote entries
and transfer progress. JSON always retains numeric byte values. Read-only
libraries still show only used space; folders still show `-`.

Common flags now have short forms wherever applicable:

- `-a/--account`
- `-j/--json`
- `-f/--overwrite`
- `-v/--verbose`
- `-t/--io-timeout`
- `-u/--username`

`-h/--help` continues to display help. Existing long flags remain available and
commands have no aliases. Size-input flags still accept both numeric bytes and
unit suffixes.

Validation covers readable/exact modes, JSON invariance, short/long flag
mapping, help without authentication, transfer summaries, recovery sizes,
TUI remote sizes and diagnostic formatting. Live saved-account acceptance
verified matched search, multipart/directory/ZIP transfers, server copies,
quota, and short flags. Native Linux FUSE and Windows WinFsp/console regressions
remain part of the three-platform CI matrix.

```sh
pkudisk ls -a work
pkudisk ls -b -a work
```
