# PKUDisk v0.6.0

PKUDisk provides a shared core for CLI, TUI, desktop GUI and Android, with
optional filesystem mounting.

- The repository and Go module are `github.com/unofficialpku/disk`. Run `pkudisk`
  (`pkudisk.exe` on Windows) for command help, `pkudisk tui` for the terminal
  interface, or `pkudisk gui` for the desktop interface.
- Desktop launchers, tray menus and the Android launcher display **PKUDisk**.
  Native configuration, cache and state directories use `pkudisk`.
- Android uses application ID `su.zzi.pkudiskfuse`. The signed APK contains
  arm64-v8a and x86_64 libraries and its dependency license texts.
- One `checksums.txt` covers all desktop archives and the Android APK.

Download the archive for Linux, macOS or Windows on amd64/arm64, verify it against
`checksums.txt`, and put `pkudisk` on `PATH`. Only mounting requires FUSE, macFUSE
or WinFsp. To install from source:

```sh
go install github.com/unofficialpku/disk/cmd/pkudisk@v0.6.0
pkudisk version
pkudisk gui
```

For Android 10 and later, install `pkudisk_0.6.0_android.apk`.
