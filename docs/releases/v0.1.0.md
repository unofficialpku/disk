# PKUDisk v0.1.0

The first public release of this project: browse, upload, download and mount
PKUDisk from Linux, macOS and Windows.

## Install

Download the archive for your operating system and CPU from the
[v0.1.0 release](https://github.com/unofficialpku/disk/releases/tag/v0.1.0).
`amd64` means Intel/AMD x86-64; `arm64` includes Apple Silicon and Windows on ARM.
Verify its SHA-256 against `checksums.txt`, extract it, and put the included
executable in a directory on your `PATH`. No Go installation is needed for these
binaries.

Then start with:

```sh
pkudisk account add
pkudisk ls
pkudisk tui
```

## Included

- PKU IAAA login, saved accounts, default-account selection and session renewal.
- Remote library/directory listing, with optional JSON output.
- Standalone uploads and downloads with progress and cancellation; checked
  destination selection and atomic local downloads.
- Multipart uploads that negotiate server limits. A generated 20 GiB file was
  uploaded and downloaded with matching hashes without a large local test file.
- A searchable Bubble Tea TUI with a local upload picker and transfer progress.
- Native Linux/macOS FUSE and Windows WinFsp mounts, using the shared write
  cache, revision conflict checks and retained-write recovery.
- Offline command help and Bash, Zsh, Fish and PowerShell completion scripts.
- The official Apache-2.0 license text and bundled dependency license files.

## Mount requirements and current limits

The CLI and TUI do not require a filesystem driver. Mounting requires FUSE on
Linux, macFUSE with its kernel extension enabled on macOS, or architecture-matched
WinFsp on Windows. FSKit is not supported.

Native Linux FUSE and Windows WinFsp mounts are tested in CI. Native macOS
CLI/storage tests and packaged-binary checks run in CI; mounting still needs
acceptance on a Mac with macFUSE enabled. The six OS/architecture binaries are
cross-built; hosted smoke tests run the runner's native architecture.

Transfers currently handle individual files, not recursive directory trees.
Server quotas and policies still apply. Mount writes use a local cache; the
default cache limit is 10 GiB and `--cache-limit 0` disables that limit.

This is a v0 release: command behavior and on-disk formats may evolve before v1.
See the included README and `docs/platform-support.md`, or run
`pkudisk help COMMAND` for usage and examples.
