# PKUDisk v0.3.9

`mount --all-accounts` exposes every saved account as a first-level directory,
with that account's accessible libraries inside. Linux/macOS FUSE and Windows
WinFsp share the same implementation. `--account/-a` still selects one exact
saved name; other commands keep their existing account selection.

Each account has independent sessions, inodes, permissions and cache identities,
including when two accounts expose identical remote IDs. The mount reuses the
existing shared cache budget and read scheduler. All accounts are checked before
mounting; idle sessions renew independently and errors identify the account.
The mounted account set is fixed until remounting and the saved default stays
unchanged.

Virtual account directories are read-only. Cross-account moves return `EXDEV`
before any remote mutation; copying files across account directories works.
Shared libraries on the same server contribute capacity once, with available
space only if at least one mounted account can write there. Read-only libraries
contribute used space only; `--read-only` reports zero available space. Pending
write recovery records include the owning account/server and original remote IDs.

`--all-accounts` cannot be combined with `--account`, `--root`, `--server`,
explicit credentials, or `--no-save`. Names must be usable local directory
names; Windows rejects reserved names and case-insensitive collisions. No
command aliases, wildcard account selection, or dependencies were added.

Validation covers concurrent cache isolation with colliding IDs/revisions,
mutation routing, early cross-account rejection, shared-library quota and
permissions, recovery retries, CLI conflicts, offline help, and authenticated
HTTP session renewal/expiration. Native FUSE and WinFsp tests exercise real
mounted multi-account reads, writes, moves and capacity. Two real saved PKU
accounts passed mounted hash checks, API-verified writes, cross-account copying,
shared-library inode/capacity checks and clean Ctrl-C unmount; temporary remote
fixtures were removed. macOS kernel mounting still requires local acceptance
with macFUSE enabled.

```sh
mkdir -p ~/PKUDisk
pkudisk mount ~/PKUDisk --all-accounts
```

On Windows, install WinFsp and run:

```powershell
.\pkudisk.exe mount P: --all-accounts
```
