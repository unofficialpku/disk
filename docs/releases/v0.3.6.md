# PKUDisk v0.3.6

Library listings now show storage usage instead of a directory size sentinel.
`ls` and `ls /` display `USED / QUOTA` with human-readable IEC units and a usage
percentage, plus `RW`/`RO` access. Shared and personal libraries use their own
server quota. A failed quota or permission query leaves the library visible,
marks the unavailable field and explains the error on stderr.

Inside a library, folders display `-` for size and regular files retain byte
counts. The JSON entry schema keeps its original fields and directory size=-1.

The existing Lip Gloss table renderer aligns wide names and numeric cells.
Regression tests cover library usage/access, query failure, folder text/JSON,
and command-to-HTTP integration. Live acceptance verified default/explicit
library listings and quota queries on the saved account.

This is a compatible patch on v0.3.5, which fixed matched searches, aggregated
mounted capacity and single-Enter Windows credential input.
