# PKUDisk v0.4.2

This patch release adds remote file management and hash based upload reuse.
The existing mount, CLI and TUI commands keep their names and account behavior.

Remote file operations:

- `delete PATH` moves a file or recursive directory into AnyShare's recycle bin.
  Destructive actions ask for confirmation; scripts must use `--non-interactive
  --yes`.
- `recycle ls [LIBRARY]` lists deleted objects from owned libraries, including
  the recycle ID, original path, deletion time and size. `recycle restore ID`
  restores a selected object; `--rename` preserves both objects on a name
  collision. `recycle remove ID` permanently deletes one object and `recycle
  empty [LIBRARY]` permanently deletes the captured listing.
- `revision ls PATH` lists retained versions. `revision restore PATH REV`
  restores a selected version after confirmation. A library can retain only the
  current version when version history is disabled by server policy.

New TUI keys are `Delete` for recycle-bin deletion, `b` for the selected
library's recycle bin, `H` for file history, and `F` to toggle instant upload.
Recycle and version restores, permanent removal and emptying all have review
screens. The all-account TUI routes these operations through the owning account,
including when remote IDs collide.

`upload --fast` checks the first 200 KiB and length, then calculates full MD5 and
CRC32 with bounded memory. A server match reuses existing content without
uploading file bytes; a miss falls back to the normal multipart/single uploader.
Existing files, including `--overwrite`, always use the revision-checked normal
path. Hashing has a separate progress phase and directory uploads apply it to
each new file.

Validation includes HTTP fixtures for pagination, invalid recycle payloads,
restore collision handling, version metadata, hash fields, mismatch fallback
and cancellation; CLI and TUI command parsing; race tests; six native cross
builds; and real temporary-account E2E. The real E2E verified instant-upload
hit and fallback, delete/list/restore, same-name `--rename`, permanent removal,
recursive directory restore and cleanup. The test server retained only the
current version for that personal library, so the version listing and restore
endpoint were verified with the available version. TUI routing and review
behavior are covered by deterministic two-account tests.

```sh
pkudisk recycle ls
pkudisk upload ./large-file.bin '/My library/large-file.bin' --fast
```
