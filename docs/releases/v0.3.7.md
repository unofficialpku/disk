# PKUDisk v0.3.7

Read-only libraries now display only their used space in the `USED` column.
Writable libraries continue to display used/quota and the usage percentage;
`ACCESS` distinguishes `RW` and `RO`. A read-only library's quota is not offered
as writable capacity.

Mounted capacity already treats read-only libraries as used/used, with zero
available bytes. A regression now changes the read-only quota dramatically and
requires the total writable capacity to stay unchanged. Live checks with the
saved three-library account confirm the listing and mounted totals.

JSON entries and existing commands remain unchanged. This patch includes the
v0.3.5 search, Windows input and multi-library capacity fixes and the v0.3.6
listing improvements.
