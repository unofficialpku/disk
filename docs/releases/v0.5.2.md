# PKUDisk v0.5.2

This release tightens the responsive GUI layout across desktop and Android WebView.

- Compact file rows align the Material file icon and filename on one baseline.
- Size/date metadata stays directly under the filename, with a separate accessible action target.
- Long names wrap without horizontal scrolling from 320px through desktop widths.
- Recycle bin, revision history, local and remote pickers, and transfer tasks use the same compact rhythm.
- Android ships as one release APK for `su.zzi.pkudiskfuse`; no separate Android license archive is included.

The release APK is compatible with the existing `su.zzi.pkudiskfuse` installation and is signed with the stable release certificate.
