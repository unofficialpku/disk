# PKUDisk v0.4.1

`tui --all-accounts` browses every saved account in one terminal session. The
first level contains account names, followed by each account's accessible
libraries. Entering an account updates the header; `g` returns to the aggregate
root. The default remains a single-account TUI.

Mount and TUI share account/session preparation and scoped directory identities.
Uploads, downloads, directory/ZIP transfers, extraction and sharing use the
owning account's original client. Identical remote IDs visible to multiple
accounts remain distinct in navigation and refreshed selections. Internal
account prefixes never reach remote APIs.

Virtual account directories cannot be uploaded into, downloaded or shared.
Extraction destinations include the account name and cannot select another
account; raw gns:// destinations are interpreted under the current account.
Local download defaults and overwrite confirmations remain unchanged.

All saved accounts must authenticate and list their libraries before opening
the TUI. Errors identify the failed account; the default account is unchanged.
`--all-accounts` cannot be combined with `--account`, `--server`, explicit
credentials or `--no-save`. The mode uses the mount's existing directory-name
checks. Other commands still select one account, and no wildcard or alias was
added. Existing CLI commands are unchanged, so this is a patch release.

Validation covers account navigation and header context, virtual-root guards,
colliding IDs, upload/overwrite and refreshed selection, direct/ZIP directory
downloads, extraction routing, sharing recipients and account-specific session
errors. Real terminal acceptance with two saved PKU accounts exercises the
same operations and independently verifies uploads and external-link revocation.
Temporary remote fixtures are removed after acceptance. Native FUSE/WinFsp
regressions remain in the existing three-platform CI.

```sh
pkudisk tui --all-accounts
```
