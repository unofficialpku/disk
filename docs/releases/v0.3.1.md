# PKUDisk v0.3.1

This patch adds optional mount diagnostics to investigate freezes that still
occur in Windows Photos. It does not establish or fix the cause of that freeze.
The existing CLI/TUI and read-policy defaults are unchanged.

## Mount diagnostics

Run the mount from a local folder and reproduce the issue:

```powershell
.\pkudisk.exe mount P: --verbose 2> mount.log
```

Use an existing empty directory as the mountpoint on Linux/macOS. The process
stays in the foreground; Ctrl-C unmounts it. Inspect the log from another
terminal while the application is frozen:

```powershell
Get-Content .\mount.log -Tail 100
```

- Timestamps and numbered `START`/`END` operations show duration and parent
  relationships. An unmatched `START` marks outstanding work, including a
  callback waiting for a lock before it can read file state.
- Filesystem entries include paths, handles, offsets, byte counts, metadata
  refresh/reuse, whole-file/sequential/range decisions, cache hits/misses,
  shared fetches, read-slot waits, eviction, retention, uploads and unmount.
- HTTP entries distinguish authentication/API calls from object transfers,
  show connection setup/reuse, response status and request timing, and mark
  the wait for response headers, first body bytes and body completion.
- Credentials, cookies, request/response bodies, query parameters and signed
  object paths are omitted. Unknown error text and unrecognized range headers
  are also omitted. Names, document IDs, hosts and local paths remain visible.
- Diagnostics are disabled by default. `--debug` additionally emits raw
  filesystem-driver messages. Requests that never reach the process, including
  a stall within Photos or WinFsp before a callback, require driver/app tracing.

## Validation and upgrade

Tests verify logs appear before a blocked lock or response body completes,
request data/errors remain unchanged, nested operations stay correlated, and
credentials/signed URL details do not enter the trace. Native mounted-file
tests exercise verbose logging with Linux FUSE and Windows WinFsp JPEG/GDI+
decoding and memory mapping. The Photos GUI itself is unavailable on CI.

Replace the executable and restart existing mounts.

```sh
pkudisk version
```

Compatible mount fixes and tuning will continue as patch releases within the
stable minor version. Saved accounts, command names and license text retain
their existing format. WinGet publication remains deferred.
