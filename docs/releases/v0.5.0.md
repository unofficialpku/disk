# PKUDisk v0.5.0

This release adds a browser GUI to the existing CLI/TUI executable and introduces
PKUDisk for Android. All surfaces share account/session handling, transfer
operations, sharing, recycle management and revision restore.

## Desktop GUI

- Run `pkudisk gui` to open the Chinese/English interface. The desktop tray
  can reopen it; Linux/macOS detach from the terminal by default. Use
  `pkudisk gui stop` to stop the background instance.
- Browse and search libraries, upload/download files and directories, manage
  sharing, recycle entries, history, mounts and retained writes. Local paths are
  chosen with a visual picker; Go does not open native file dialogs.
- The local HTTP service uses one-use activation links, bearer API sessions and
  strict origin checks. A stopped service replaces the workspace with a blocking
  message so stale windows cannot continue issuing operations.
- The sidebar places the version beside Quit. Empty account views show one Add
  Account action; loading, errors, empty directories and filtered results have
  distinct states. Narrow-screen history and picker layouts keep actions visible.

## Android

- Install the APK from the
  [v0.5.0 release](https://github.com/unofficialpku/disk/releases/tag/v0.5.0)
  on Android 10 or later.
  It includes arm64 phones and x86_64 emulators, package
  `su.zzi.pkudiskfuse`, version code 2.
- The shared Go core runs in-process through gomobile. Android System WebView
  owns the interface, standard document selection and DownloadManager handle
  files, and no external Chrome app or custom JavaScript download bridge is used.
- Active work shows native task progress notifications without a Quit action.
  Idle use has no persistent notification. An idle background app releases the
  service and resumes it when reopened; ongoing tasks keep it running until they
  finish. Explicit Quit closes the app and removes its recent task.
- Mobile screens hide mounting and desktop controls. Unexpected service loss
  displays “服务未运行，请退出应用” / “The service is not running. Please exit the app.”
- The release APK is not debuggable. Android dependency license texts
  accompany the APK in a separate archive.

## Core and development

`internal/session`, `internal/mount`, `internal/anyshare`, `internal/vfs` and
`internal/transfer` share business operations across all surfaces. TUI components
and terminal rendering now live in internal packages. The root `go.work` links
the separate mobile module for development, while standalone CLI builds and
releases retain their own dependency graph. `PKUDISK_GUI_DEV_PROXY` supports Nuxt
HMR through the authenticated Go origin. Unit tests and browser/Android E2E use
the same AnyShare fixture.

```sh
pkudisk gui
```

Desktop archives still support Linux, macOS and Windows on amd64/arm64. Only
filesystem mounting requires FUSE/macFUSE/WinFsp. See the included platform and
GUI documentation for setup and supported operations.

Android background work remains subject to OS and manufacturer limits, including
the dataSync time budget. Attachments use a short-lived authorization handoff;
offline scheduling and resumable download authorization are not implemented.
iOS binding generation is supported, but an iOS application and runtime validation
still require macOS/Xcode. Samsung hardware has not been tested here.
