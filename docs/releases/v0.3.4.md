# PKUDisk v0.3.4

This patch adds small server-side utilities and corrects mounted free-space
reporting.

## Changes

- FUSE and WinFsp now report the authenticated AnyShare quota's writable
  remaining bytes (`allocated - used`) for `statfs`/drive free-space queries.
  Local cache disk space is no longer presented as remote capacity. Quota
  values are briefly cached and invalidated after mount mutations.
- Added `util quota` for allocation/usage, `util search` for bounded remote
  filename search, and `util copy` for server-side file/folder copies.
- `util copy` polls asynchronous directory-copy jobs and never transfers file
  bytes through the local machine. Server permission, approval and storage
  policies still apply.
- Existing transfer, mount, account, TUI and path syntax remain unchanged.

## Validation

The quota, search, copy and FUSE statfs protocols have HTTP fixture tests.
Read-only live probes against PKU returned quota, search and recycle responses;
the live quota was also exposed through `util quota`. Linux/macOS tests, the
Windows cross-platform vet check, race tests and the existing native mount
suite pass on the release commit.

```sh
pkudisk version
```

The official client was only unpacked under `/tmp` and inspected read-only.
No offline URL, BitTorrent or magnet task API was found in it.
